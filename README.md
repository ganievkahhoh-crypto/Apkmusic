# AI Клипы — Android-плеер с генерацией визуалов

Плеер, который подбирает кадры к песне: находит синхронный текст (LRCLIB),
разбивает его на сцены, просит нейросеть придумать кадр под каждую сцену
и генерирует картинки через Pollinations (модель turbo, без ключей и регистрации).

## Сборка APK без Android Studio (GitHub Actions)

1. Загрузите файлы этого архива в **корень** репозитория GitHub
   (важно: не папку целиком, а её содержимое).
2. Убедитесь, что в репозитории есть `.github/workflows/build-apk.yml`
   (папка `.github` скрытая — некоторые проводники её не копируют;
   если её нет, создайте файл через «Add file → Create new file»,
   введя путь `.github/workflows/build-apk.yml`).
3. Вкладка Actions дождётся сборки (5–10 минут), артефакт `app-debug-apk` — ваш APK.

## Сборка локально (Android Studio)

Открыть папку проекта, дождаться синхронизации Gradle, Run.

## Как пользоваться

1. «Выбрать трек» — mp3/m4a/wav из памяти телефона.
2. Поля «Исполнитель» и «Название» — для поиска текста (подставляются из имени файла вида «Artist - Title.mp3»).
3. «Собрать клип» — плеер найдёт текст, соберёт сцены и начнёт играть с генерацией кадров в фоне.

## Скорость

- Модель `turbo`: кадр за ~5–15 секунд (вместо 30–60 у flux).
- Кадры генерируются с опережением на 2 сцены вперёд; если не успели —
  держится предыдущий кадр с движением камеры, без разрывов.
- Разрешение 768x768 — на экране телефона разницы с большим не видно.

## Архитектура

- `Core.kt` — LRCLIB (точный запрос + поиск), парсер LRC, группировка в сцены.
- `Director.kt` — текстовая модель Pollinations придумывает кадры,
  фолбэк — встроенный словарь мотивов (хрущёвка, окно, силуэты, дорога, ночь…).
- `Renderer.kt` — генерация картинок, единый стиль и seed на трек.
- `MainActivity.kt` — ExoPlayer, тикер таймкодов, кроссфейд, Ken Burns.

## Следующий шаг (оживление кадров)

В `Renderer.render()` вместо картинки запрашивать image-to-video
(AnimateDiff локально или облачный API) — композер не меняется.
